## Analysis of Airbnb listings and neighborhood NYC data in R.

This repository contains two scripts for a group assignment for the course Programming for Data Analytics (University of Cologne).

1.  Data preprocessing (airbnb_prep.R)
2.  Text analysis (airbnb_text.R)

In this project, I also largely contributed to the exploratory data analysis. That code was written and revised together with my teammates, so it can't be clearly attributed to individual group members, therefore I don't include it here.

Part of the Airbnb dataset consists of synthetically generated data added by the course lecturer for teaching purposes. The goal of the group assignment was to apply data analysis skills in R (data wrangling, visualization, statistical models, text analysis).

### Datasets (not included in the repository):

- Airbnb listings in New York City (48,895 listings); provided for the course.

- [NYC Neighborhood Health Atlas](https://www.nyc.gov/site/doh/health/neighborhood-health/nyc-neighborhood-health-atlas.page) for neighborhood indicators.
